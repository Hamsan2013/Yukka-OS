# Yakka Language

Yakka is the terminal language of Yukka OS.

## Statements

```text
let name = "Buddy"
print name

let total = 10 + 20
print total

if total > 20
print "Big"
end

repeat 5
print "Hello"
end

function hello()
print "Welcome"
end

hello()
```
